- **Python** — linguagem utilizada nos experimentos.

- **NumPy** — operações numéricas.

- **Statsmodels** — análise estatística e regressão.
- **Google Colab** — desenvolvimento e execução dos notebooks.
- **Git e GitHub** — versionamento e documentação dos estudos.

## Projetos e atividades

### Regressão Linear

Notebook: `regressao3.ipynb`

Experimento com regressão linear utilizando Python, Pandas, Statsmodels e Scikit-learn, explorando a relação entre características de imóveis e seus preços.

O notebook utiliza variáveis como tamanho do imóvel e quantidade de quartos para estudar a previsão de preços.

## Ambiente de desenvolvimento
